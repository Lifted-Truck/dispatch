# e2b-roundup — cross-project portfolio board (E2b body of work)

- **Queue item:** ROADMAP E2b — Roadmap roundup (deterministic). Also closes
  E2 (human ratified 2026-07-24).
- **Why:** FACTS are a delta — a phase fact is emitted only when the phase
  changes — so a project parked on one phase for a month is invisible in the
  daily digest. E2b renders the standing state of every watched project.
- **What was built:** `dispatch/snapshot.py` (pure: observations + date ->
  `dispatch-snapshot.1`, with staleness computed from the collection date,
  never the clock), `dispatch/roundup.py` (pure: snapshot -> self-contained
  HTML board), `bin/roundup`, and a `last_commit_date` probe read. The
  snapshot is produced from the SAME observations as FACTS in one collection
  pass (one collector, two renderings) rather than a second tree walk.
  `dispatch/theme.py` extracts the shared palette so digest and board cannot
  drift; the E2 goldens proved the digest's bytes unchanged by that
  refactor.
- **Evidence consulted:** ROADMAP E2b gate; the E2 renderer for house style;
  registry.json `derived_status` semantics (un-normalized projects are swept
  anyway, marked inferred-vs-declared); real run over 55 projects.
- **Bug found and fixed:** the ROADMAP phase parser missed
  `**Phase C0 — Consolidation.**` (two-token id) — autonomous carried the
  marker but reported no phase. Regex now strips an optional `Phase ` prefix;
  regression test added. Detected phases went 2 -> 3.
- **Alternatives rejected:** a multi-convention phase parser inferring phase
  from `- [x]` checkboxes / ✅ / TODO-WIP-DONE tables. 26 projects have a
  ROADMAP in one of those forms, but they are TASK lists — reading "first
  unchecked item" as a phase would emit confidently wrong rows, the
  invisible-failure mode. Filed as a blocking open question for the human
  instead (their convention, not dispatch's code). Also rejected: a second
  tree walk for the snapshot (wasteful; same observations serve both).
- **Verify:** full, exit 0; 53 unit tests — 11 snapshot-assembly, 9 board
  tests incl. golden byte-stability, every-project-exactly-once,
  inferred-vs-declared carried through, escaping, no-network. Real board
  over 55 projects: 0 absolute paths in snapshot or page.
- **Open questions:** phase detection beyond the marker (ROADMAP open
  questions); E2b gate ratification is the human's call.
