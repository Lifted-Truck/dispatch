# e2-renderer — deterministic digest renderer built (E2 body of work)

- **Queue item:** ROADMAP E2 — Renderer (deterministic); plus E2b added to
  the roadmap at the human's request (cross-project roadmap roundup board).
- **Why:** E2 opened on E1's ratification. Built `dispatch/render.py`
  (pure FACTS-doc -> self-contained HTML page; no clock, no network, no
  model calls) and `bin/render`; pinned two golden renders (active-day and
  quiet-day fixtures).
- **Evidence consulted:** ROADMAP E2 gate; charter §Domain (verify targets,
  facts-before-prose); the E1 FACTS schema in dispatch/facts.py; real
  render of facts/2026-07-10.json inspected in the browser (DOM checks:
  43 cards, footer, computed colors — the pane's screenshot pipeline
  glitched after the first frame, so verification below the fold was
  DOM/text-level, not pixel-level).
- **Alternatives rejected:** a template engine dependency (string assembly
  in stdlib keeps the no-dependency stance and byte-stability trivially
  auditable); putting golden tests in a separate full-only suite (they run
  in ~0.1s, so they live in tests/unit and the fast gate — full ⊇ fast
  still satisfies the charter's "full = fast + golden-render" and no
  verify edit was needed).
- **Verify:** full, exit 0 (structure + ruff + 31 unit tests incl. golden
  byte-stability, quiet-day render, no-network assertions, escaping).
  Git hash recorded post-commit in .harness/last-verify.json.
- **Open questions:** E2 gate ratification is the human's call; digest
  visual design is a first draft — voice/format preferences (open ROADMAP
  question) may reshape it; E2b needs a collector snapshot mode (phase
  facts currently only emitted on change).
